# 提交材料说明（“三智能体”AI赋能版）

本目录为申报「重庆市教育评估院 2026 年教育评价领域典型实践案例」的成果材料。

## 文件清单

1. `师范生教育教学能力认定抽检评价改革实践-案例文稿.docx` —— 案例正文，结构含案例背景、具体举措及实施成效、实施成效、经验总结；图1~图4 已用占位行标出，请自行插入截图。
2. `附件1 教育评价领域典型实践案例征集表.docx` —— 已按附件 1 模板填写。
3. `generate_docs.py` —— 文档生成脚本，修改后可重新生成。

## 主题与类别

- 案例类别：**学生成长**（评价对象为师范生，聚焦其教育教学能力核心素养监测）。

## 合规情况

- **字数**：正文 Word 口径约 **2711 字**（中文 2663 字），符合“3000 字以内”要求。
- **结构**：已统一为三部分——“一、案例背景／二、具体举措及实施成效（含（六）实施成效）／三、经验总结”。

## ⚠️ 需要注意的事项

1. **图片**：图1~图4 为占位行 `［请在此处插入图片］`，请在 Word 中替换为实际截图。
2. **标题**：当前主/副标题为建议拟定，可按需调整。
3. **待填信息**：征集表中【】标注的单位全称、作者姓名/单位/电话/邮箱、单位性质勾选、获奖情况、推荐意见盖章等，请据实补充；文中量化数据（20→10 分钟、约50%、30 个百分点、10 余所、30 余个、500 余名等）请与实际一致。

## 重新生成文档

```bash
pip install python-docx
python3 generate_docs.py
```
