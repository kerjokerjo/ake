# 提交材料说明

本目录为申报「重庆市教育评估院 2026 年教育评价领域典型实践案例」的成果材料。

## 文件清单

1. `师范生教育教学能力认定抽检评价改革实践-案例文稿.docx` —— 案例正文（含"案例背景""具体举措及实施成效""经验总结"三部分，约 1500 字，符合 3000 字以内要求）。
2. `附件1 教育评价领域典型实践案例征集表.docx` —— 已按附件 1 模板填写的征集表。
3. `generate_docs.py` —— 上述 Word 文档的生成脚本，便于后续修改后重新生成。

## 主题与类别

- 案例类别：**学生成长**（聚焦学生评价、学业质量监测；本案例评价对象为师范生）。
- 政策背景：师范生免试认定中小学教师资格改革下的省级教育教学能力认定**抽检**。

## 提交前需补充/确认的内容（文中以【】标注）

请用本单位真实数据替换以下占位符，避免空泛：

- 案例单位全称、作者姓名、作者单位、联系电话、电子邮箱。
- 征集表"类别"一栏：按本单位性质勾选（区县教科研院所 / 评估监测机构 / 高校 / 中小学校（含中职学校）/ 幼儿园）。
- 运行年限【X】年、覆盖【XX】所院校、【XX】个师范专业、【XX】名师范生等量化数据。
- 如有区级及以上获奖，请据实填写并附佐证材料；如无则保留"无"。
- 推荐意见栏由所属单位填写并盖章、署日期。
- 量化成效（如评审周期压缩比例、配置时间缩短幅度等）建议补充真实数据以增强说服力。

## 重新生成文档

```bash
pip install python-docx
python3 generate_docs.py
```
