# 项目讲解评分标准

项目讲解占 50%，每个维度由各评委独立打分取平均值。

一、通用加/扣分项

| 项目 | 分值 |
| --- | --- |
| 时间控制优秀（误差 ≤1 分钟） | +2 |
| 严重超时或不足 3 分钟 | -5 |
| PPT 精美、结构清晰 | +2 |
| 现场演示故障未解决 | -3 |
| 表达清晰自信 | +2 |
| 态度不端正 | -5 |

二、C1 环境搭建与项目启动（T3，满分 100）

90~100：清晰讲解 Spring Initializr 与 pom.xml 依赖，自定义 `ContestProperties` 正确演示，Actuator 在线展示，能对比起步依赖与传统依赖。80~89：能讲解项目结构与依赖，配置与 Properties 基本正确。70~79：能讲解结构但对起步依赖解释不清。60~69：仅能说明启动方式。<60：未能演示或讲解严重错误。

三、C2 持久层与事务（T4，满分 100）

90~100：讲解 MP BaseMapper、LambdaQueryWrapper、分页；现场演示事务回滚；正确解释传播与隔离级别。80~89：能讲基本事务场景，传播机制略有瑕疵。70~79：能讲 CRUD 但对一致性理解不深。60~69：仅能演示 CRUD。<60：无法演示。

四、C3 自定义 Starter 与自动装配（T5，满分 100）

90~100：准确解释 `@SpringBootApplication` 结构与 `@EnableAutoConfiguration` 加载流程；演示条件装配；分析 Starter 设计思想。80~89：能讲 Starter 与自动装配基本原理。70~79：对原理解释不深。60~69：停留在概念层。<60：讲解内容错误。

五、C4 单元测试与接口测试（T6，满分 100）

90~100：演示 Service/Controller/端到端三层测试，解释 MockMvc 与 Mockito 差异；展示 JaCoCo 报告；分析用例设计思路。80~89：演示两层测试，覆盖率 ≥60%。70~79：能演示基本测试但覆盖率不足。60~69：仅有个别用例。<60：未有效编写。

六、C5 RESTful 接口与文档（T7，满分 100）

90~100：能对照 REST 规范讲接口设计；统一响应与全局异常规范；Knife4j 文档分组合理、示例完整；现场演示 Postman。80~89：接口合规，文档可访问。70~79：少量不规范但整体可用。60~69：规范性差。<60：接口错误或未接入文档。

七、C6 AOP 与权限控制（T8，满分 100）

90~100：深入讲解切点表达式、`@Around` 原理、JoinPoint；演示自定义注解 + AOP 的日志/权限；说明拦截器与 AOP 差异。80~89：能讲日志切面与登录拦截器及适用场景。70~79：能讲基本 AOP 但原理一般。60~69：仅能演示 AOP 日志。<60：实现错误。

八、成绩记录样例

每位评委对每位学生的 C1~C6 单独打分，取平均值作为该维度的讲解得分。例：学生张三 C1 得分由三位评委打 85/88/86，最终 C1 讲解得分 = (85+88+86)/3 = 86.33。
