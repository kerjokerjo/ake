# 项目讲解评分标准（50%）

> 项目讲解部分对应 C1~C6 六个维度（合计 60%）。每个维度评分标准按 5 档展开：优秀（90~100）、良好（80~89）、中等（70~79）、及格（60~69）、不及格（<60）。
> 每位学生每个维度的讲解得分由评委独立打分，取算术平均值。

## 通用加/扣分项

| 加/扣分项 | 分值 |
|---|---|
| 时间控制优秀（误差 ≤ 1 分钟） | +2 |
| 严重超时或不足 3 分钟 | -5 |
| PPT 制作精美，结构清晰 | +2 |
| 现场演示故障未能解决 | -3 |
| 普通话清晰、表达自信 | +2 |
| 使用不当语言或态度不端正 | -5 |

## C1：环境搭建与项目启动（T3，满分 100）

| 等级 | 评分要点 |
|---|---|
| 90~100 | 清晰讲解 Spring Initializr 创建过程，能说明 pom.xml 每类依赖的作用；自定义 `ContestProperties` 正确演示；Actuator 健康检查在线演示；能对比起步依赖与传统依赖的差异 |
| 80~89 | 能讲解项目结构与 pom 依赖；配置文件与自定义 Properties 基本正确；Actuator 可演示 |
| 70~79 | 能讲解项目结构但对起步依赖机制解释不清；配置文件基本使用 |
| 60~69 | 讲解内容零散，仅能说明项目如何启动 |
| <60 | 未能成功演示项目启动或讲解内容严重错误 |

## C2：持久层与事务（T4，满分 100）

| 等级 | 评分要点 |
|---|---|
| 90~100 | 能讲解 MyBatis-Plus BaseMapper 用法、LambdaQueryWrapper、分页插件；能现场演示 `@Transactional` 回滚场景，并正确解释事务传播、隔离级别 |
| 80~89 | 能讲解 MyBatis-Plus 使用与基本事务场景，事务传播机制解释略有瑕疵 |
| 70~79 | 能讲解基本 CRUD，但对事务一致性场景理解不深入 |
| 60~69 | 仅能演示 CRUD，未涉及事务管理 |
| <60 | 持久层实现错误或无法现场演示 CRUD |

## C3：自定义 Starter 与自动装配（T5，满分 100）

| 等级 | 评分要点 |
|---|---|
| 90~100 | 能深入讲解 `@SpringBootApplication` 注解结构，准确解释 `@EnableAutoConfiguration` 加载流程；能演示条件装配（`@ConditionalOnProperty` 开关）效果；能分析 Starter 机制的设计思想 |
| 80~89 | 能讲解 Starter 机制与自动装配基本原理，演示条件装配 |
| 70~79 | 能讲解 Starter 模块结构，但对原理解释不深入 |
| 60~69 | 对自动装配仅停留在概念层面 |
| <60 | 未能独立完成 Starter 或讲解内容错误 |

## C4：单元测试与接口测试（T6，满分 100）

| 等级 | 评分要点 |
|---|---|
| 90~100 | 能演示 Service / Controller / 端到端三层测试，解释 MockMvc 与 Mockito 的差别；现场展示 JaCoCo 覆盖率报告；能分析测试用例设计思路（正常/边界/异常） |
| 80~89 | 能演示 Service 与 Controller 测试，覆盖率 ≥ 60%，测试设计合理 |
| 70~79 | 能演示基本的单元测试，但覆盖率不足 |
| 60~69 | 仅有个别测试用例，缺少覆盖率统计 |
| <60 | 未编写有效测试用例 |

## C5：RESTful 接口与文档（T7，满分 100）

| 等级 | 评分要点 |
|---|---|
| 90~100 | 能讲解 REST 规范与本项目接口设计的对应关系；统一响应体与全局异常处理规范；Knife4j 文档分组合理、示例完整；能现场演示 Postman 测试 |
| 80~89 | 接口设计符合 REST 规范，文档可访问 |
| 70~79 | 接口设计存在少量不规范，但整体可用 |
| 60~69 | 接口基本能用，但 REST 规范性差 |
| <60 | 接口设计错误或未接入 Swagger/Knife4j |

## C6：AOP 与权限控制（T8，满分 100）

| 等级 | 评分要点 |
|---|---|
| 90~100 | 能深入讲解 AOP 切点表达式、`@Around` 原理、JoinPoint 获取方法信息的过程；能演示自定义注解 + AOP 的日志/权限实现；解释拦截器与 AOP 的差异 |
| 80~89 | 能讲解 AOP 日志切面与登录拦截器，且能区分二者适用场景 |
| 70~79 | 能讲解 AOP 基本用法，但对原理解释一般 |
| 60~69 | 仅能演示 AOP 日志 |
| <60 | AOP 或拦截器实现错误 |
