# 项目答辩题库

> 题库按课程目标 T3~T8 分类，每个课程目标下分基础题、进阶题、挑战题三个难度层。
> 评委在答辩时可根据学生讲解深度从题库中抽取 3~5 题提问。每位学生至少被问到 1 题。

## 一、T3 — 环境搭建与自动配置（C1，对应 8%）

### 1.1 基础题（每题难度系数 1.0）

1. 请简述 Spring Initializr 创建 Spring Boot 项目的完整流程，并说明 `pom.xml` 中 parent 的作用。
2. `application.yml` 与 `application.properties` 二者的区别？同时存在时哪个优先？
3. 你的项目中使用了哪些起步依赖（`spring-boot-starter-*`）？请至少说 3 个并解释其功能。
4. 如何实现多环境（dev/test/prod）配置切换？请举例说明。
5. `@ConfigurationProperties` 和 `@Value` 二者有哪些区别？你项目中选择了哪个？为什么？

### 1.2 进阶题（难度系数 1.2）

6. 你的 `ContestProperties` 是如何自动加载到 Spring 容器的？绑定过程中如果字段名不匹配会发生什么？
7. 请现场修改 `application.yml` 中某项配置，让它立即生效（不重启服务）——可以如何实现？
8. 项目中如果 `application-dev.yml` 与 `application.yml` 都配置了 `server.port`，最终生效的是哪一个？Why？
9. Spring Boot 默认会加载哪几类外部配置源？优先级顺序是什么？
10. Actuator 的 `health` 端点背后是什么机制实现的？如何自定义健康检查？

### 1.3 挑战题（难度系数 1.5）

11. 假设生产环境配置通过 Nacos 下发，你会如何把 Nacos 配置与本地 `application.yml` 无缝整合？
12. `spring.profiles.active=dev,prod` 这种多 profile 组合会怎样生效？
13. 如何在 Spring Boot 启动时对 Bean 属性进行 Bean Validation 校验？

## 二、T4 — 持久层与事务（C2，对应 12%）

### 2.1 基础题

1. 你的项目中引入 MyBatis-Plus 的主要依赖是什么？BaseMapper 提供了哪些开箱即用的方法？
2. `@TableId` 有哪些 type？你项目中使用了哪种？
3. LambdaQueryWrapper 相比 QueryWrapper 的优势是什么？
4. MyBatis-Plus 的分页插件如何配置？默认情况下不配置分页插件会怎样？
5. `@Transactional` 注解可以加在哪些位置？加在 private 方法上会生效吗？

### 2.2 进阶题

6. 你的报名接口中如何保证"新增报名记录"和"更新用户报名次数"的事务一致性？
7. 请解释事务传播行为 REQUIRED、REQUIRES_NEW、NESTED 的区别，分别举一个适用场景。
8. Spring 事务失效的常见场景有哪些？（如自调用、异常被 catch、非 public 方法等）
9. 如何实现 MyBatis-Plus 的逻辑删除？逻辑删除字段默认查询时会做什么处理？
10. 如何处理"一对多"关系查询？（如一个学生多次报名）

### 2.3 挑战题

11. 如果希望"跨多个数据源"执行事务，应该如何处理？（引出 JTA 或分布式事务）
12. 请谈谈 MyBatis-Plus 自动填充（MetaObjectHandler）的使用场景与原理。
13. 如何实现乐观锁？在报名场景中如何应用？

## 三、T5 — 自定义 Starter 与自动装配（C3，对应 10%）

### 3.1 基础题

1. `@SpringBootApplication` 是由哪三个注解组合而成的？
2. 请解释 `@EnableAutoConfiguration` 的作用。
3. 自定义 Starter 的标准命名规则是什么？请说出 Spring Boot 官方 Starter 与第三方 Starter 的命名差异。
4. `spring.factories` 和 `AutoConfiguration.imports` 二者用法有何区别？哪一个是 Spring Boot 2.7+ 推荐的？
5. 你的 `contest-log-spring-boot-starter` 提供了哪些自动装配的 Bean？

### 3.2 进阶题

6. 请解释 `@ConditionalOnClass`、`@ConditionalOnProperty`、`@ConditionalOnMissingBean` 的使用场景。
7. 自动装配是在 Spring Boot 启动的哪个阶段加载的？背后通过什么机制完成？
8. 你是如何在主工程中"零配置"使用自己的 Starter 的？请演示一次开关关闭时 Bean 是否存在。
9. Spring Boot 3.x 对自动装配做了哪些改动？你项目采用的是哪个版本？
10. 如果主工程中同时存在相同类型的 Bean（自定义的和 Starter 提供的），应该如何让用户自定义的 Bean 优先生效？

### 3.3 挑战题

11. 请手写一段 `@ConditionalOnExpression` 条件注解的 SpEL 表达式。
12. 请解释 `ImportSelector` 与 `DeferredImportSelector` 的区别，并举一个 Spring Boot 源码中使用它们的案例。
13. 自动装配与 Spring Framework 的 `@Import` 机制有什么关联？

## 四、T6 — 测试（C4，对应 10%）

### 4.1 基础题

1. `@SpringBootTest` 与 `@WebMvcTest` 的差异？你项目各用了哪个？
2. MockMvc 的常用方法有哪些？请举例说明如何验证 JSON 响应。
3. 什么是 Mock？Mockito 中 `@Mock` 和 `@MockBean` 的区别是什么？
4. 你项目的测试覆盖率是多少？用什么工具统计？
5. 请解释 JUnit 5 的参数化测试（`@ParameterizedTest`）的用法。

### 4.2 进阶题

6. 你是如何为"事务回滚"场景编写测试用例的？
7. `@SpringBootTest(webEnvironment = RANDOM_PORT)` 背后做了哪些事？
8. 请说明"单元测试"与"集成测试"的差别，你项目中各有多少个？
9. 如何在测试中切换 profile？（`@ActiveProfiles` 等）
10. 在 MockMvc 中如何模拟已登录用户的上下文？

### 4.3 挑战题

11. 测试报名业务时，如何断言"发生并发报名时乐观锁生效"？
12. 请谈谈契约测试、端到端测试、冒烟测试的异同。
13. 你会如何在 CI 中集成单元测试、覆盖率检查、门禁？

## 五、T7 — RESTful 接口与文档（C5，对应 9%）

### 5.1 基础题

1. REST 风格的 6 大约束中，你认为最核心的是哪 3 条？
2. `@GetMapping`、`@PostMapping`、`@PutMapping`、`@DeleteMapping` 分别对应什么语义？
3. `@RequestBody`、`@PathVariable`、`@RequestParam` 适用于哪些场景？
4. 你项目中的统一响应体结构是什么？请现场演示一个成功响应和一个业务异常响应。
5. Knife4j 和 Swagger / SpringDoc 的关系是什么？

### 5.2 进阶题

6. 如何用 `@RestControllerAdvice` 统一处理异常？有哪些优先级陷阱？
7. 一个 POST `/api/registrations` 请求体参数校验失败时，你的系统返回的 HTTP 状态码是多少？响应体结构是什么？
8. REST 接口中，幂等性如何保证？幂等与等效的区别？
9. 你是如何在接口文档中区分"管理员接口"与"学生接口"的？
10. 请解释 HATEOAS，以及为什么大多数项目没有严格实现它。

### 5.3 挑战题

11. 如何在接口文档中演示"上传文件"？请给出 `@Operation` / `@Schema` 的写法。
12. 如果要做灰度发布，如何在 REST 接口层面支持？
13. 如果一个接口需要返回流式数据，应该如何设计？

## 六、T8 — AOP 与权限控制（C6，对应 11%）

### 6.1 基础题

1. AOP 是什么？Spring AOP 与 AspectJ 的关系是？
2. `@Around` 与 `@Before` / `@AfterReturning` 的适用场景有什么不同？
3. JoinPoint 可以获取哪些信息？你如何通过 JoinPoint 打印方法参数？
4. 拦截器（HandlerInterceptor）与 Filter、AOP 三者的差别？
5. 你项目的登录校验是放在 Filter、拦截器还是 AOP 中？为什么？

### 6.2 进阶题

6. 请演示 `@OperLog` 注解的切点表达式，并解释为什么这样写。
7. 同一个 Controller 方法既被 `@OperLog` 匹配也被性能监控切点匹配，二者执行顺序如何？
8. 如何让 AOP 对"自调用"（同类中的方法调用）也能生效？
9. 请说明 JWT Token 的结构及校验流程。
10. `@RequiresRole("ADMIN")` 切面中如何获取当前登录用户信息？

### 6.3 挑战题

11. 请谈谈 AOP 的动态代理（JDK 动态代理 vs CGLIB）差异，以及 Spring Boot 默认选择哪种。
12. 如果在切面中再抛出异常，对原方法的事务会产生什么影响？
13. 若使用 Spring Security，你的拦截器方案与它有何异同？
