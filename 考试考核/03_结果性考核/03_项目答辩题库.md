# 项目答辩题库

按 T3~T8 分类，每目标分基础（★）、进阶（★★）、挑战（★★★）三档。答辩时评委可抽取 3~5 题，每位学生至少被问 1 题。

一、T3 环境搭建与自动配置（C1，8%）

基础：①Spring Initializr 创建项目流程，pom parent 作用？②`.yml` 与 `.properties` 区别，同时存在哪个优先？③常用 3 个起步依赖及其功能。④多环境（dev/test/prod）切换如何实现？⑤`@ConfigurationProperties` 与 `@Value` 的区别？

进阶：⑥`ContestProperties` 如何自动加载，字段不匹配会怎样？⑦不重启如何让配置生效？⑧`application-dev.yml` 与 `application.yml` 同时配 `server.port`，最终以哪个为准？⑨Spring Boot 外部配置的加载顺序？⑩Actuator `health` 背后机制，如何自定义健康检查？

挑战：⑪Nacos 配置与本地如何整合？⑫`spring.profiles.active=dev,prod` 如何生效？⑬如何在启动时对 Bean 做 Bean Validation？

二、T4 持久层与事务（C2，12%）

基础：①MP 主要依赖、BaseMapper 方法？②`@TableId` 的 type 都有哪些？③LambdaQueryWrapper 相对 QueryWrapper 的优势？④分页插件配置，不配会怎样？⑤`@Transactional` 可放在哪些位置，private 方法会生效吗？

进阶：⑥如何保证"新增报名 + 更新报名次数"事务一致？⑦REQUIRED/REQUIRES_NEW/NESTED 的区别与场景？⑧事务失效的常见场景？⑨MP 的逻辑删除如何实现？⑩一对多关系查询如何处理？

挑战：⑪跨多数据源的事务怎么处理？⑫MP 自动填充（MetaObjectHandler）的使用场景与原理？⑬乐观锁在报名场景如何应用？

三、T5 自定义 Starter 与自动装配（C3，10%）

基础：①`@SpringBootApplication` 由哪三个注解组成？②`@EnableAutoConfiguration` 作用？③自定义 Starter 命名规则？④`spring.factories` 与 `AutoConfiguration.imports` 的区别？⑤自定义 Starter 提供了哪些自动装配 Bean？

进阶：⑥`@ConditionalOnClass/Property/MissingBean` 的场景？⑦自动装配在启动的哪个阶段加载？⑧如何零配置使用 Starter？⑨Spring Boot 3.x 对自动装配的改动？⑩同类型 Bean 冲突如何让用户自定义优先？

挑战：⑪`@ConditionalOnExpression` 的 SpEL 示例？⑫`ImportSelector` 与 `DeferredImportSelector` 的区别？⑬自动装配与 `@Import` 的关联？

四、T6 测试（C4，10%）

基础：①`@SpringBootTest` 与 `@WebMvcTest` 差异？②MockMvc 常用方法及 JSON 断言？③Mockito `@Mock` 与 `@MockBean` 的区别？④测试覆盖率及工具？⑤JUnit 5 参数化测试用法？

进阶：⑥事务回滚场景如何测？⑦`@SpringBootTest(webEnvironment=RANDOM_PORT)` 做了什么？⑧单元测试与集成测试差别？⑨如何切换 profile？⑩如何模拟已登录用户上下文？

挑战：⑪并发报名场景如何测乐观锁？⑫契约测试、端到端、冒烟测试差异？⑬CI 中如何集成测试与覆盖率门禁？

五、T7 RESTful 接口与文档（C5，9%）

基础：①REST 6 大约束中你认为最核心的 3 条？②`@GetMapping/@PostMapping/@PutMapping/@DeleteMapping` 的语义？③`@RequestBody/@PathVariable/@RequestParam` 适用场景？④统一响应体结构？⑤Knife4j 与 Swagger/SpringDoc 关系？

进阶：⑥`@RestControllerAdvice` 统一异常的陷阱？⑦参数校验失败的状态码与响应体？⑧幂等性如何保证，幂等与等效的区别？⑨接口文档如何区分管理员与学生？⑩HATEOAS 与为何大多数项目不严格实现？

挑战：⑪文件上传如何在文档中演示？⑫灰度发布如何在接口层支持？⑬返回流式数据如何设计？

六、T8 AOP 与权限控制（C6，11%）

基础：①AOP 是什么，Spring AOP 与 AspectJ 关系？②`@Around` 与 `@Before/@AfterReturning` 场景差异？③JoinPoint 可获取的信息？④Filter/拦截器/AOP 差异？⑤登录校验放在哪，为什么？

进阶：⑥`@OperLog` 切点表达式？⑦日志与性能监控切点都命中时执行顺序？⑧自调用如何让 AOP 生效？⑨JWT Token 结构与校验流程？⑩切面中如何获取当前登录用户？

挑战：⑪JDK 动态代理 vs CGLIB，Spring Boot 默认哪种？⑫切面中再抛异常对事务的影响？⑬与 Spring Security 拦截器方案的异同？
