# 项目答辩考核实施方案（结果性评价，60%）

> 本方案对应《课程目标达成度评价报告》表 7 中"结果性评价 — 项目答辩成绩（60%）"的考核。
> 成绩构成：**项目讲解（50%）+ 项目答辩（50%）**。
> 考核对应 T3~T8 共 6 个课程目标，考核项编号 C1~C6。

## 一、考核目的

通过综合性项目答辩检验学生对 Spring Boot 核心配置、自动化装配、持久层开发、框架底层机制、测试、RESTful、AOP 等知识点的综合应用能力，以及分析问题、解决问题、技术表达的能力，支撑专业人才培养方案中相关培养规格指标点的达成。

## 二、考核形式

- **形式**：分组答辩（3~5 人/组），每组答辩时间 **30 分钟**（讲解 15 分钟 + 答辩 15 分钟）。
- **地点**：实训机房。
- **考核方式**：小组互评 + 教师评分。
- **评委组**：课程负责人 1 人 + 任课教师 2 人 + 企业导师 1 人（可选），共 3~4 人。

## 三、考核内容（依托项目）

以"竞赛登记管理系统"为共同选题，或小组自主选定 1 个符合课程目标要求的 Java Web 项目。项目需完整实现以下六个维度，分别对应 C1~C6。

| 考核项 | 课程目标 | 权重 | 考核内容 |
|---|---|---|---|
| C1 | T3 | 8% | 项目骨架搭建、环境配置、启动运行 |
| C2 | T4 | 12% | MyBatis-Plus 持久层实现、事务管理、数据交互 |
| C3 | T5 | 10% | 自定义 Starter 设计、自动装配原理应用 |
| C4 | T6 | 10% | 单元测试、集成测试、测试覆盖率 |
| C5 | T7 | 9% | RESTful 接口设计、Swagger/Knife4j 文档 |
| C6 | T8 | 11% | AOP 日志、拦截器、权限控制 |

合计：**60%**

## 四、项目讲解环节（50%）

### 4.1 讲解要求

每位学生须讲解本人在项目中负责的模块，讲解内容包括：
1. 模块功能与业务价值（2 分钟）
2. 核心技术点与实现思路（8 分钟）
3. 关键代码现场演示（3 分钟）
4. 学习心得与难点总结（2 分钟）

### 4.2 讲解评分项（共 6 个维度，对应 C1~C6 分项）

| 评分维度 | 对应考核项 | 分值 | 评价要点 |
|---|---|---|---|
| 环境搭建与项目启动 | C1 | 8% | 项目结构清晰，依赖配置合理，现场启动无报错 |
| 持久层与事务 | C2 | 12% | MyBatis-Plus 使用得当，事务场景合理 |
| 自定义 Starter 与自动装配 | C3 | 10% | 能解释自动装配原理，Starter 设计合规 |
| 单元测试与接口测试 | C4 | 10% | 测试用例设计合理，覆盖率 ≥ 60% |
| RESTful 接口与文档 | C5 | 9% | 接口规范，文档可访问且注解完整 |
| AOP 与权限控制 | C6 | 11% | 切面设计合理，拦截器 + 权限校验正确 |

## 五、项目答辩环节（50%）

### 5.1 答辩要求

评委基于项目讲解内容、项目源码、文档提出 3~5 个技术问题，学生现场作答。题目从《项目答辩题库》中随机抽取，覆盖 T3~T8 各课程目标。

### 5.2 答辩评分项（与讲解一致，按 C1~C6 维度独立评分）

每个维度下，评委根据学生对该维度相关问题的回答质量打分，分项得分 × 维度权重得到最终分值。

## 六、总评计算

对每位学生，每个考核项 C_i 的最终得分为：

```
C_i 最终得分 = 项目讲解得分 × 50% + 项目答辩得分 × 50%
```

学生在结果性评价中的总得分：

```
结果性成绩 = C1×8% + C2×12% + C3×10% + C4×10% + C5×9% + C6×11%   （满分 60 分）
```

## 七、答辩流程

1. **答辩前 1 周**：学生提交项目源码、数据库脚本、项目答辩 PPT、个人贡献说明。
2. **答辩前 1 天**：评委抽签确定答辩顺序与题目池。
3. **答辩当天**：
   - 10 分钟：小组整体介绍（项目背景、技术栈、架构）
   - 15 分钟：每位学生依次讲解自己负责的模块
   - 15 分钟：评委提问，小组成员回答（每人至少被提问 1 个问题）
   - 5 分钟：评委评分与小组互评
4. **答辩后 3 天内**：教师汇总成绩，填写《项目答辩成绩汇总表》，提交教研室。

## 八、答辩纪律

1. 答辩过程全程录像，作为评价原始材料。
2. 学生须着正装，礼貌回答，不得中途退场。
3. 对答辩成绩有异议的，可在 3 个工作日内向教学干事提交复核申请。
4. 抄袭、代答等作弊行为经核实后，本项成绩记 0 分并上报学院。
