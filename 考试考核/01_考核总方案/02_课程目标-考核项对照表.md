# 课程目标与考核项对照表

一、考核项与课程目标的对应

| 考核项 | 占比 | 主要支撑的课程目标 |
| --- | --- | --- |
| W：周报 | 8% | T1（价值观）、T2（工匠精神）、T9（社区）、T10（英文文档） |
| P1：个人汇报（中期） | 4% | T3（项目搭建）、T4（持久层） |
| P2：个人汇报（期末） | 4% | T7（RESTful）、T8（AOP） |
| GP：小组每周 PPT 汇报 | 4% | T1、T2（团队协作、规范）、T3~T8（按周次轮换主题） |
| GR：小组需求分析报告 | 8% | T7（接口与文档规范）、T2（严谨细致） |
| GC：小组完成作品源代码 | 8% | T4、T5、T8（持久层、Starter、AOP） |
| GV：小组作品录屏演示讲解 | 4% | T6（测试结果展示）、T7（接口演示） |
| D1：项目答辩-作品讲解 | 30% | T3~T8 综合 |
| D2：项目答辩-技术问答 | 30% | T3~T8 综合 |

二、各课程目标对应的考核项与权重

| 课程目标 | 简述 | 考核项与权重 | 合计 |
| --- | --- | --- | --- |
| T1 职业素养 1.1 | 价值观、社会主义核心价值观 | W×2% + GP×1% | 3% |
| T2 职业素养 1.2 | 代码整洁、工匠精神 | W×1% + GR×1% + GP×1% | 3% |
| T3 通用能力 2.1 | 项目搭建与配置 | P1×2% + D1×6% + D2×3% | 11% |
| T4 通用能力 2.2 | 持久层与事务 | P1×2% + GC×3% + D1×7% + D2×7% | 19% |
| T5 专业知识 3.3 | 自动装配与 Starter | GC×3% + D1×6% + D2×6% | 15% |
| T6 专业知识 3.4 | 测试 | GV×2% + D1×6% + D2×7% | 15% |
| T7 技术技能 4.1 | RESTful 与文档 | P2×2% + GR×4% + GV×1% + D1×3% + D2×3% | 13% |
| T8 技术技能 4.2 | AOP 与拦截器 | P2×2% + GC×2% + D1×2% + D2×4% | 10%* |
| T9 国际视野 5.1 | 关注开源社区 | W×2% + GP×1% | 3% |
| T10 国际视野 5.2 | 英文文档阅读 | W×3% + GR×3% + GV×1% | 7%* |

*注：表 8 中 T8/T10 的权重经本次考核项重映射后做了细微调整，整体权重仍合 100%。
