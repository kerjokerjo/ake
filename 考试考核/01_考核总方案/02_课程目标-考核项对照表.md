## 二、考核项归属说明

### 2.1 过程性考核中的"课堂表现"（4%）

由 A1（2%）+ A2（2%）构成，体现在 T1、T2。其中 A3（2%）、A4（2%）归于国际视野，虽然评价场景同为课堂，但单独作为 T9、T10 的支撑，合计 4%。

> 在总评成绩中，A1~A4 共 8% 属于"课堂讨论/团队协作"相关定性评分；其中 A1、A2 主要覆盖职业素养类"课堂表现"部分，A3、A4 覆盖国际视野类"课堂表现"部分。

### 2.2 过程性考核中的"线上学习"（4%）

由 B1（1%）+ B2（1%）+ 部分 B 类作业中"线上学习进度、答疑讨论"的维度构成。B1 侧重 JavaWeb 开发工具使用，B2 侧重 Vue.js 开发工具使用，体现线上学习成果。

### 2.3 过程性考核中的"课堂及课后作业"（32%）

由 B3（3%）+ B4（7%）+ B5（5%）+ B6（5%）+ B7（4%）+ B8（6%）构成，合计 **30%**（另 2% 由 B1、B2 补足至 32%，体现作业平台的日常评分权重）。

### 2.4 结果性评价中的"项目答辩"（60%）

由 C1（8%）+ C2（12%）+ C3（10%）+ C4（10%）+ C5（9%）+ C6（11%）构成，合计 **60%**。
答辩由"项目讲解（50%）"与"项目答辩（50%）"两部分组成，每位学生的 C1~C6 分项得分均为两部分的加权平均。

## 三、权重验证

| 考核项分组 | 合计 |
|---|---|
| A1 + A2 + A3 + A4 | 2% + 2% + 2% + 2% = 8% |
| B1 + B2 | 1% + 1% = 2% |
| B3 + B4 + B5 + B6 + B7 + B8 | 3% + 7% + 5% + 5% + 4% + 6% = 30% |
| C1 + C2 + C3 + C4 + C5 + C6 | 8% + 12% + 10% + 10% + 9% + 11% = 60% |
| **合计** | **100%** |

其中：课堂表现 = A1+A2 = 4%；国际视野课堂表现 = A3+A4 = 4%（独立计入 T9/T10）；线上学习 = B1+B2 = 2%；作业 = B3~B8 = 30%；作业+线上学习合计 32%；项目答辩 60%。与报告表 7 一致。
