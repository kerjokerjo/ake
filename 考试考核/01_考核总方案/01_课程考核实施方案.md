# 《Web 项目实战》课程考核实施方案

| 项目 | 内容 |
|---|---|
| 课程名称 | Web 项目实战 |
| 课程代码 | 32093143 |
| 适用专业 | 软件技术 |
| 考核性质 | 考试 |
| 课程类型 | 理论+实践 |
| 总学时 | 64（理论 32 + 实践 32） |
| 评价周期 | 每学期一次，在课程考核结束后进行 |
| 达成标准 | 课程目标达成值 ≥ 0.7 为达成 |

## 一、考核指导思想

本课程围绕"Web 项目实战实战能力"培养，按照课程标准与培养规格指标点，结合过程性考核与终结性考核相结合的原则，对学生的学习态度、工具使用能力、理论知识掌握、编码实操能力、综合项目实战能力进行系统评价，落实立德树人根本任务，培养学生敬业守信、善于沟通与合作、精益求精的工匠精神。

## 二、考核组成与权重

### 2.1 总体构成

| 评价组成 | 考核方式 | 评分规则 | 分值占比 |
|---|---|---|---|
| 过程性评价（40%） | 课堂表现 | 学习态度、课堂互动、小组讨论、随堂提问等 | 4% |
| 过程性评价（40%） | 线上学习 | 线上学习进度、线上课后习题、答疑讨论 | 4% |
| 过程性评价（40%） | 课堂及课后作业 | 竞赛登记管理系统功能测试、性能测试与接口测试 | 32% |
| 结果性评价（60%） | 项目答辩成绩 | 项目讲解（50%）+ 项目答辩（50%） | 60% |

### 2.2 考核项编号说明

- **A 类（课堂定性考核）**：A1~A4，对应 T1、T2、T9、T10 的课堂表现/团队协作评分
- **B 类（作业/实训平台自动评价）**：B1~B8，对应智慧教学平台作业与实训任务
- **C 类（项目答辩成绩）**：C1~C6，对应 T3~T8 的项目讲解答辩环节

## 三、课程目标达成度计算

### 3.1 各课程目标达成值公式

对第 i 个课程目标：

```
T_i 达成值 = Σ(单项考核学生实际得分 / 考核项满分 × 考核项占总成绩比) / Σ(考核项占总成绩比)
```

### 3.2 各课程目标达成度计算式（依据表 8）

| 课程目标 | 达成度计算式 |
|---|---|
| T1 | (A1/100 × 2% + B1/100 × 1%) / (2% + 1%) |
| T2 | (A2/100 × 2% + B2/100 × 1%) / (2% + 1%) |
| T3 | (B3/100 × 3% + C1/100 × 8%) / (3% + 8%) |
| T4 | (B4/100 × 7% + C2/100 × 12%) / (7% + 12%) |
| T5 | (B5/100 × 5% + C3/100 × 10%) / (5% + 10%) |
| T6 | (B6/100 × 5% + C4/100 × 10%) / (5% + 10%) |
| T7 | (B7/100 × 4% + C5/100 × 9%) / (4% + 9%) |
| T8 | (B8/100 × 6% + C6/100 × 11%) / (6% + 11%) |
| T9 | (A3/100 × 2%) / 2% |
| T10 | (A4/100 × 2%) / 2% |

### 3.3 培养规格指标点达成度

按照报告中的规格强度（H=3, M=2, L=1）对支撑该指标点的所有课程目标达成度进行加权平均。

## 四、总评成绩计算

```
总评成绩 = 0.04 × 课堂表现 + 0.04 × 线上学习 + 0.32 × 课堂及课后作业 + 0.60 × 项目答辩成绩
```

其中：
- 课堂表现 = (A1 + A2 + A3 + A4) / 4 （或按权重加权）
- 线上学习 = (B1 + B2) / 2
- 课堂及课后作业 = 按 B3~B8 对应权重加权
- 项目答辩成绩 = 项目讲解 × 50% + 项目答辩 × 50%，按 C1~C6 对应权重加权

## 五、考核评价的过程

1. **开课前**：课程命题教师填写《课程考核命题审批表》，由专业带头人审核。
2. **授课中**：按过程性考核实施细则开展 A1~A4、B1~B8 评价，保留原始记录（智慧教学平台数据、作业提交记录、课堂表现记录）。
3. **期末**：组织项目答辩，按 C1~C6 评分。
4. **考核后**：课程负责人计算课程目标达成值，填写《课程目标达成情况评价表》，开展试卷分析，形成《课程目标达成情况评价报告》。
5. **结果反馈**：教学干事汇总结果，实时反馈至相关学生、专业带头人和工作小组组长。

## 六、合格标准

- 总评成绩 ≥ 60 分为及格；
- 各课程目标达成值 ≥ 0.7 为达成；
- 整体达成度 ≥ 0.7 且所有 10 个课程目标均达成，即认为课程教学有效支撑培养规格指标点的实现。
