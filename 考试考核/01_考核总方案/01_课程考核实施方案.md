# 课程考核实施方案

一、基本信息

课程名称：Web 项目实战；课程代码：32093143；适用专业：软件技术；考核性质：考试；课程类型：理论+实践；总学时：64（理论 32 + 实践 32）；评价周期：每学期一次；达成标准：课程目标达成值 ≥ 0.7 为达成。

二、考核组成与权重

| 评价组成 | 考核方式 | 分值占比 |
| --- | --- | --- |
| 过程性（40%） | 周报（每人 8 份） | 8% |
| 过程性（40%） | 个人上台汇报（每人 2 次） | 8% |
| 过程性（40%） | 小组每周 PPT 汇报（每周 1 人） | 4% |
| 过程性（40%） | 小组需求分析报告 | 8% |
| 过程性（40%） | 小组完成作品源代码 | 8% |
| 过程性（40%） | 小组作品录屏演示讲解 | 4% |
| 结果性（60%） | 项目答辩-作品讲解（50%） | 30% |
| 结果性（60%） | 项目答辩-技术问答（50%） | 30% |
| 合计 | | 100% |

三、考核项编号

为简化记录，定义如下考核项编号：

- W：每人 8 份周报的总分（个人）
- P1、P2：每位学生 2 次上台汇报得分（个人）
- GP：小组每周 PPT 汇报学期累计得分（小组每位成员同分）
- GR：小组需求分析报告（小组）
- GC：小组完成作品源代码（小组）
- GV：小组作品录屏演示讲解（小组）
- D1：项目答辩-作品讲解（个人）
- D2：项目答辩-技术问答（个人）

每位学生总评成绩 = W×8% + P1×4% + P2×4% + GP×4% + GR×8% + GC×8% + GV×4% + D1×30% + D2×30%。其中 GP/GR/GC/GV 为小组成绩，组内成员同分；W、P1、P2、D1、D2 为个人成绩。

四、达成度计算

第 i 个课程目标的达成值 = Σ（考核项实际得分 / 满分 × 占比）/ Σ（占比）。班级整体达成值按全班平均分计算，学生个体达成值按个体成绩计算。

五、合格标准

总评成绩 ≥ 60 为及格；各课程目标达成值 ≥ 0.7 为达成。

六、实施流程

1. 开课前：命题教师填写《课程考核命题审批表》，由专业带头人审核。
2. 授课中：每周收周报、组织 PPT 汇报、记录评分；学期内安排 2 次个人上台汇报。
3. 学期末前 1~2 周：小组提交需求分析报告、源代码、录屏演示。
4. 期末：组织项目答辩，按 D1、D2 评分。
5. 考核后：计算达成值，填写《课程目标达成情况评价表》。

编制：廖清科；审核：专业带头人；批准：分管教学副院长。
