## 考核构成（依据表 7、表 8）

| 评价组成 | 考核方式 | 评分规则 | 分值占比 |
|---|---|---|---|
| 过程性评价 | 课堂表现 | 学习态度、课堂互动、小组讨论、随堂提问等 | 4% |
| 过程性评价 | 线上学习 | 线上学习进度、线上课后习题、答疑讨论 | 4% |
| 过程性评价 | 课堂及课后作业 | 竞赛登记管理系统功能测试、性能测试与接口测试 | 32% |
| 结果性评价 | 项目答辩成绩 | 项目讲解（50%）+ 项目答辩（50%） | 60% |

合计：**100%**；其中过程性 **40%**，结果性 **60%**；课程达成度 `≥ 0.7` 为达成。

## 使用说明

1. 开课前：课程负责人填写 `04_命题审批与评分表/01_课程考核命题审批表.md`，经专业带头人、分管教学副院长审核。
2. 授课中：按 `02_过程性考核/` 下的实施细则落实 A1~A4、B1~B8 的评价工作，保留原始记录。
3. 期末：按 `03_结果性考核/` 组织项目答辩，填写 `04_项目答辩成绩汇总表.md`。
4. 考核后：汇总成绩至 `01_考核总方案/03_成绩汇总与达成度计算模板.md`，并填写 `04_命题审批与评分表/04_课程目标达成情况评价表模板.md` 与 `03_试卷分析模板.md`，形成《课程目标达成情况评价报告》。
