# 定性考核评分标准（课堂表现、团队协作、实训表现）

引用《课程目标达成度评价报告》表 9，结合 T1、T2、T9、T10 考核要点供教师打分参考。

一、课堂表现

| 分段 | 评分标准 |
| --- | --- |
| 90~100 | 全程专注，无迟到早退；主动参与提问研讨，回答准确且能拓展实战；主动分享见解，带动交流氛围 |
| 80~89 | 专注度高，偶迟到即整改；主动互动，回答基本准确；按时完成课堂即时测试，质量达标 |
| 70~79 | 基本专注，1~2 次迟到；被动参与，答案无原则错误；按时完成任务，质量基本符合 |
| 60~69 | 注意力不集中，3 次内迟到；极少主动互动；小组讨论参与度低，任务延迟 |
| <60 | 多次迟到缺勤；课堂走神拒不参与；未完成任务或存在严重知识性错误 |

二、团队协作（基于团队软件开发项目）

| 分段 | 评分标准 |
| --- | --- |
| 90~100 | 主动承担核心测试任务，责任心强；精准对接成员，主动协调分歧；团队核心贡献者，获全员认可 |
| 80~89 | 主动接受任务无推诿；按时沟通反馈问题；认真完成工作，获成员认可 |
| 70~79 | 接受任务履行职责；配合团队沟通，对分歧无过激行为；按时完成基础工作 |
| 60~69 | 被动接受任务，有轻微推诿；沟通不积极，多次提醒才反馈；完成工作但有疏漏 |
| <60 | 不接受任务或脱离团队；拒不沟通，隐瞒问题引发分歧；未完成任务导致进度滞后 |

三、实训表现（含实操、规范、成果）

| 分段 | 评分标准 |
| --- | --- |
| 90~100 | 独立高效完成 Spring Boot 项目搭建、配置与功能开发；熟练运用自动装配、Starter；严守编码规范、文档完整、主动总结心得 |
| 80~89 | 独立完成核心功能，代码规范偶有细微疏漏；掌握核心配置与持久层；遵守规范、提交心得 |
| 70~79 | 在少量指导下完成开发，存在 3~4 处疏漏；能使用基本工具；按时提交资料 |
| 60~69 | 需较多指导，代码有明显漏洞修正后可运行；工具使用不熟练；资料延迟或敷衍 |
| <60 | 多次指导仍无法完成核心功能；无法使用基本工具；多次违规、资料严重缺失 |

四、与 T1/T2/T9/T10 映射

| 考核项 | 课程目标 | 主要评分依据 |
| --- | --- | --- |
| A1 网络法治意识 | T1 | 课堂表现 + 团队协作中体现的价值观与开源协作精神 |
| A2 严谨开发意识 | T2 | 课堂表现 + 实训表现中体现的工匠精神与代码规范 |
| A3 开源社区使用 | T9 | 课堂讨论中对 Spring 官方 Blog/GitHub 的关注 |
| A4 英文文档阅读 | T10 | 课堂展示的英文文档阅读与分享情况 |

教师每周至少对每位学生在以上三个环节打分 1 次，每月汇总一次；期末取学期内的算术平均值作为最终得分。
