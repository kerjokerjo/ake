# 课堂及课后作业任务书合集

依托项目：竞赛登记管理系统。每个任务提供目标、要求、交付物、评分要点。

一、B3 搭建"竞赛登记管理系统"工程骨架（T3，3%）

目标：使用 Spring Initializr 创建 Spring Boot 项目，掌握起步依赖、application.yml 与自定义配置绑定。

要求：①项目坐标 com.cqvie.contest；②引入 Web、Validation、DevTools、Lombok、MySQL、MyBatis-Plus、Actuator 等起步依赖；③配置 application.yml 与 dev/prod 多环境；④自定义 `ContestProperties` 绑定 `contest.name/version/max-registration-per-user`；⑤实现 `HealthCheckController`，访问 `/api/info` 返回配置；⑥启用 Actuator 的 health/info。

交付物：可启动项目（Git 链接）、README、启动与访问截图。

评分要点：项目启动 20 / 依赖配置 15 / 多环境配置 20 / 自定义 Properties 20 / Actuator 10 / README 15。

二、B4 使用 MyBatis-Plus 实现 CRUD 与事务（T4，7%）

目标：整合 MyBatis-Plus 实现用户/竞赛/报名/成绩表的 CRUD；掌握分页、条件查询、声明式事务。

要求：①MySQL 5.7 建库 `contest_registration`，建表 `t_user / t_contest / t_registration / t_score`；②实现实体、Mapper、Service 三层；③实现单体 CRUD、分页、LambdaQueryWrapper 条件查询；④`RegistrationServiceImpl.register` 使用 `@Transactional`，保证"新增报名 + 更新报名次数"事务一致，超限抛 `BizException` 回滚；⑤JUnit 测试覆盖全部 Service 方法，通过率 100%。

交付物：SQL 脚本、源码、单测、任务报告。

评分要点：数据库建模 15 / MP 配置 15 / CRUD 25 / 分页+条件查询 15 / 事务一致性 20 / 单元测试 10。

三、B5 开发自定义"操作日志"Starter（T5，5%）

目标：理解 `@SpringBootApplication`、自动装配与条件注解；开发可"开箱即用"的 Starter。

要求：①新建 Maven 子模块 `contest-log-spring-boot-starter`；②提供 `ContestLogProperties`（前缀 `contest.log`，含 enabled/save-to-db/async/max-content-length）、`ContestLogService`、`ContestLogAutoConfiguration`（`@ConditionalOnProperty(... matchIfMissing=true)`）；③配置 `AutoConfiguration.imports`（2.7+）或 `spring.factories`（2.x）；④主工程引入 Starter，零配置可用；⑤单测验证装配开关；⑥提交 ≥800 字原理分析报告（含 `@SpringBootApplication` 结构、自动装配流程、与官方 Starter 差异）。

交付物：Starter 模块源码、主工程示例、单测、原理报告。

评分要点：结构规范 15 / 装配文件配置 15 / 条件装配 20 / 开箱即用验证 15 / 单测 15 / 原理报告 20。

四、B6 编写 Service 单元测试与接口测试（T6，5%）

目标：掌握 `@SpringBootTest`、MockMvc、Mockito、JaCoCo。

要求：①Service 单测覆盖 3 大 Service 的正常/边界/异常场景，覆盖率 ≥70%；②Controller 使用 MockMvc 覆盖 GET/POST/PUT/DELETE，含参数校验与异常测试；③用 `@SpringBootTest(webEnvironment=RANDOM_PORT)` + TestRestTemplate 编写 1 个端到端测试；④集成 JaCoCo 生成 HTML 报告；⑤提交测试分析报告，列出每个用例的目的/输入/期望/实际。

交付物：测试代码、JaCoCo 报告、测试分析报告。

评分要点：Service 覆盖率 20 / Service 场景覆盖 15 / Controller MockMvc 20 / 端到端 15 / JaCoCo 报告 10 / 分析报告 20。

五、B7 实现 RESTful 接口并生成在线文档（T7，4%）

目标：设计符合 REST 规范的接口，整合 Knife4j/SpringDoc 生成在线文档。

要求：①为 `/api/users`、`/api/contests`、`/api/registrations` 每个资源设计 ≥5 个接口；②统一响应体 `Result<T>`（code/message/data/timestamp）；③`@Valid` + `@NotBlank/@Size/@Pattern` 参数校验；④`@RestControllerAdvice` 统一异常处理；⑤整合 Knife4j（`/doc.html`）或 SpringDoc（`/swagger-ui/index.html`），为每个接口添加 `@Operation/@Tag/@Parameter/@Schema` 注解。

交付物：接口源码、可访问的在线文档（截图）、Postman 集合、接口设计说明。

评分要点：REST 规范 20 / 统一响应与异常 20 / 参数校验 15 / Knife4j 接入 20 / 文档注解 15 / Postman 集合 10。

六、B8 使用 AOP 与拦截器实现日志与权限（T8，6%）

目标：掌握 Spring AOP、拦截器、自定义注解 + AOP 实现权限控制。

要求：①AOP 日志切面：自定义注解 `@OperLog(value, module, saveRequestData)`，`@Around` 记录入参/出参/耗时/调用者 IP，日志异步写入 `t_oper_log`；②性能监控切面：对所有 Service 方法统计耗时，>500ms 输出 WARN 慢方法告警；③`LoginInterceptor`：拦截除 `/api/auth/login`、`/doc.html`、`/actuator/**` 外的请求，校验 `Authorization: Bearer <token>`，解析 JWT 放入 ThreadLocal，无效/过期返回统一 401；④`@RequiresRole("ADMIN")` 注解 + AOP 校验角色，不匹配返回 403；⑤单测覆盖以上 4 类场景。

交付物：切面与拦截器源码、自定义注解、`t_oper_log` 日志截图（≥20 条）、单测与报告。

评分要点：日志切面 25 / 性能监控 15 / 登录拦截器 20 / 权限注解 15 / 日志数据 10 / 单测 15。

七、提交与评审流程

学生在智慧教学平台提交源码链接与任务报告 → 平台 CI 自动执行 `mvn clean verify` 获取构建结果、测试通过率、覆盖率 → 教师按《评分要点》打分 → 平台合成最终得分。
