   Page<Contest> page = new Page<>(pageNum, pageSize);

2. [★★★] 请基于你的 `RegistrationService` 写出保证"报名记录新增 + 用户报名次数更新"的事务代码。

   ```java
   @Service
   public class RegistrationServiceImpl implements RegistrationService {
       @Autowired private RegistrationMapper registrationMapper;
       @Autowired private UserMapper userMapper;
       @Autowired private ContestProperties contestProperties;

       @Transactional(rollbackFor = Exception.class)
       @Override
       public void register(Long userId, Long contestId) {
           User user = userMapper.selectById(userId);
           if (user.getRegisterCount() >= contestProperties.getMaxRegistrationPerUser()) {
               throw new BizException("超出最大报名次数");
           }
           Registration reg = new Registration();
           reg.setUserId(userId); reg.setContestId(contestId);
           reg.setRegisterTime(LocalDateTime.now());
           registrationMapper.insert(reg);
           user.setRegisterCount(user.getRegisterCount() + 1);
           userMapper.updateById(user);
       }
   }
   ```

### 3.2 简答题

1. [★★★] 请根据以下需求编写一个自定义注解 `@OperLog` 与对应的切面。
   - 需求：标注在 Controller 方法上，切面在方法执行后异步记录：操作名（注解 value）、方法参数、返回值、耗时、调用者 IP。

   ```java
   // 自定义注解
   @Target(ElementType.METHOD)
   @Retention(RetentionPolicy.RUNTIME)
   public @interface OperLog {
       String value() default "";
       String module() default "";
       boolean saveRequestData() default true;
   }

   // 切面
   @Aspect
   @Component
   public class OperLogAspect {
       @Autowired private OperLogService logService;

       @Around("@annotation(operLog)")
       public Object around(ProceedingJoinPoint pjp, OperLog operLog) throws Throwable {
           long start = System.currentTimeMillis();
           Object result = null;
           Throwable ex = null;
           try {
               result = pjp.proceed();
               return result;
           } catch (Throwable t) { ex = t; throw t; }
           finally {
               long cost = System.currentTimeMillis() - start;
               logService.saveAsync(buildRecord(pjp, operLog, result, ex, cost));
           }
       }
   }
   ```
