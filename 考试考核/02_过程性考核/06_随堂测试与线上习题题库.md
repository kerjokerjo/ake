单选：①Spring AOP 默认代理方式是 C.根据是否实现接口自动选择。②方法前后都执行的是 C.`@Around`。

多选：适合用 AOP 的场景：日志、性能监控、权限、事务（ABCD）。

判断：①AOP 对自调用不生效（√）。②HandlerInterceptor 只拦 Spring MVC 请求（√）。

编程：请写出 `@OperLog` 自定义注解及对应切面（`@Around("@annotation(operLog)")`，记录入参/出参/耗时/IP，异步入库）。参考：

```java
@Target(ElementType.METHOD) @Retention(RetentionPolicy.RUNTIME)
public @interface OperLog { String value() default ""; String module() default ""; boolean saveRequestData() default true; }

@Aspect @Component
public class OperLogAspect {
    @Autowired private OperLogService logService;
    @Around("@annotation(operLog)")
    public Object around(ProceedingJoinPoint pjp, OperLog operLog) throws Throwable {
        long start = System.currentTimeMillis();
        try { return pjp.proceed(); }
        finally { logService.saveAsync(buildRecord(pjp, operLog, System.currentTimeMillis()-start)); }
    }
}
```
