# 线上学习考核实施细则（B1、B2）

> 本细则对应总评成绩中的"线上学习（4%）"与"课堂及课后作业"中 B1、B2 的评分。
> B1 对应 T1（职业素养 1.1，1%）；B2 对应 T2（职业素养 1.2，1%）。

## 一、考核项概述

| 考核项 | 对应课程目标 | 考核维度 | 权重 | 满分 |
|---|---|---|---|---|
| B1 | T1（职业素养 1.1） | JavaWeb 开发工具的使用能力 | 1% | 100 |
| B2 | T2（职业素养 1.2） | Vue.js 开发工具的使用能力 | 1% | 100 |

> 注：B1、B2 在报告中合计 2%，作为线上学习 4% 中的工具使用能力评价部分；剩余 2% 由"线上学习进度、答疑讨论"等日常行为分构成，由智慧教学平台自动计算。

## 二、评价方式与数据来源

- **评价方式**：智慧教学平台授课评价
- **数据来源**：
  1. 在线视频学习完成进度（MOOC 平台 / 智慧教学平台）；
  2. 线上课后习题完成率与正确率；
  3. 答疑讨论区的提问与回帖质量；
  4. 开发工具使用的作品上传（如 IDE 项目截图、操作录屏）。

## 三、B1 JavaWeb 开发工具的使用能力评分（支撑 T1）

### 3.1 考核内容

围绕 JavaWeb 后端开发常用工具，包括：
- IntelliJ IDEA / Eclipse 项目创建、配置、调试
- Maven 依赖管理、打包、部署
- Spring Initializr 创建 Spring Boot 项目
- Git 版本管理
- Postman / ApiFox 接口测试
- JDK、Tomcat 等运行环境配置

### 3.2 线上学习任务（占 B1 的 100%）

| 任务编号 | 任务内容 | 任务形式 | 分值 |
|---|---|---|---|
| B1-L1 | 完成"IDEA + Maven + JDK"环境搭建课程学习 | 观看视频 + 完成线上习题 | 15 |
| B1-L2 | 完成"Spring Initializr 创建项目"线上实操任务 | 上传项目截图 + 线上答题 | 15 |
| B1-L3 | 完成"Git 版本管理基础"学习与作业 | 在线代码仓库操作 + 习题 | 15 |
| B1-L4 | 完成"Postman 接口测试"学习与实操 | 上传 Postman 集合导出文件 | 15 |
| B1-L5 | 完成"Tomcat 部署 SpringBoot War 包"任务 | 上传部署截图 + 习题 | 15 |
| B1-L6 | 线上答疑讨论区发起提问或回帖质量 | 讨论区记录 | 15 |
| B1-L7 | 线上学习进度（覆盖本课程全部章节） | 学习进度 ≥95% 计满分 | 10 |

### 3.3 B1-L1~L5 每任务评分标准

| 分数段 | 评分标准 |
|---|---|
| 13~15 | 任务完整、操作规范、截图 / 习题准确，体现工具熟练度 |
| 10~12 | 任务基本完整，操作规范，少量瑕疵 |
| 7~9 | 任务基本完成，操作存在 1~2 处明显不规范 |
| 4~6 | 任务完成度不足，操作存在较多问题 |
| 0~3 | 未完成或严重敷衍 |

## 四、B2 Vue.js 开发工具的使用能力评分（支撑 T2）

### 4.1 考核内容

围绕 Vue.js 前端开发常用工具，包括：
- Node.js、npm/pnpm 环境搭建
- Vue CLI / Vite 项目创建
- VSCode + Vetur / Volar 插件使用
- Vue Devtools 调试
- axios + Mock.js 接口联调
- 前端构建打包、部署到 Nginx

### 4.2 线上学习任务（占 B2 的 100%）

| 任务编号 | 任务内容 | 任务形式 | 分值 |
|---|---|---|---|
| B2-L1 | 完成"Node.js + npm 环境搭建"课程学习 | 视频 + 习题 | 15 |
| B2-L2 | 完成"Vue CLI 创建 Vue 2 项目"任务 | 上传项目截图 + 习题 | 15 |
| B2-L3 | 完成"VSCode 插件配置与使用"任务 | 截图 + 习题 | 15 |
| B2-L4 | 完成"axios 发起请求与联调"任务 | 源码提交 + 习题 | 15 |
| B2-L5 | 完成"Vue 项目构建部署到 Nginx"任务 | 部署截图 + 习题 | 15 |
| B2-L6 | 线上答疑讨论区发起提问或回帖质量 | 讨论区记录 | 15 |
| B2-L7 | 线上学习进度（覆盖本课程全部章节） | 学习进度 ≥95% 计满分 | 10 |

### 4.3 B2-L1~L5 每任务评分标准

（与 B1 相同等级标准）

## 五、线上答疑讨论区质量评分（B1-L6 / B2-L6）

| 等级 | 行为描述 |
|---|---|
| 13~15 | 每周至少 1 次高质量提问或 2 次高质量回帖，能体现独立思考 |
| 10~12 | 每两周至少 1 次提问或回帖，内容有价值 |
| 7~9 | 偶尔参与讨论，内容基本合格 |
| 4~6 | 仅有 1~2 次参与 |
| 0~3 | 未参与讨论 |

## 六、记录与反馈

1. 智慧教学平台自动汇总学习进度与习题成绩，教师定期抽查截图与项目源码。
2. 每月向学生反馈一次线上学习完成情况，对进度低于 60% 的学生发出预警。
3. 期末：汇总各任务得分，乘以权重，得到 B1、B2 最终分值。
