# 课堂及课后作业实施细则（B3~B8）

> 本细则对应总评成绩中的"课堂及课后作业（32%）"中的 B3~B8（合计 30%）。
> 作业依托"竞赛登记管理系统"真实项目开展，覆盖 T3~T8 六个课程目标。

## 一、考核项概述

| 考核项 | 对应课程目标 | 考核内容 | 权重 | 满分 | 评价方式 |
|---|---|---|---|---|---|
| B3 | T3（通用能力 2.1） | 创建项目并成功启动服务 | 3% | 100 | 智慧教学平台自动评价 |
| B4 | T4（通用能力 2.2） | 整合 MyBatis-Plus 实现增删改查 | 7% | 100 | 智慧教学平台自动评价 |
| B5 | T5（专业知识 3.3） | 实现自定义 Starter 自动装配 | 5% | 100 | 智慧教学平台自动评价 |
| B6 | T6（专业知识 3.4） | 编写 Service 单元测试与接口测试 | 5% | 100 | 智慧教学平台自动评价 |
| B7 | T7（技术技能 4.1） | 实现 RESTful 接口并生成文档 | 4% | 100 | 智慧教学平台自动评价 |
| B8 | T8（技术技能 4.2） | 使用 AOP 实现日志记录切面 | 6% | 100 | 智慧教学平台自动评价 |

## 二、依托项目

**项目名称**：竞赛登记管理系统（ContestRegistrationSystem）

**核心功能模块**：
1. 用户管理（学生、指导教师、管理员三类角色）
2. 竞赛信息管理（发布、修改、查询、删除竞赛）
3. 报名管理（学生报名、指导教师审核）
4. 成绩管理（录入、查询、统计）
5. 系统日志管理（操作日志、登录日志）
6. 权限与接口文档

## 三、作业通用要求

1. **技术栈**：
   - 后端：Spring Boot 2.7.x / 3.x + MyBatis-Plus + MySQL 5.7 + Redis
   - 前端：Vue 2 + ElementUI + axios
   - 文档：Knife4j / Swagger
   - 测试：JUnit 5 + MockMvc
2. **提交要求**：
   - 源码：Git 仓库链接
   - 文档：README + 任务报告（Word / Markdown）
   - 截图：运行效果截图 + 测试截图
3. **提交方式**：智慧教学平台作业系统提交，由平台自动评价（代码质量 / 单元测试 / 接口正确性 / 构建结果）+ 教师复核。
4. **时间节点**：每项作业在对应教学单元结束后 1 周内提交。

## 四、B3~B8 任务清单简表

| 编号 | 任务名称 | 对应知识点 | 主要交付物 |
|---|---|---|---|
| B3 | 搭建"竞赛登记管理系统"工程骨架 | Spring Initializr、pom.xml、application.yml、Swagger、健康检查 | 可启动的 Spring Boot 工程 |
| B4 | 使用 MyBatis-Plus 实现学生 / 竞赛 / 报名模块的 CRUD | MyBatis-Plus、@Transactional、分页、多表关联 | Service、Mapper、Controller 代码与单测 |
| B5 | 开发自定义操作日志 Starter | 自动装配、条件注解、Starter 机制 | 独立的 `contest-log-spring-boot-starter` 模块 |
| B6 | 编写 Service 单元测试与接口测试 | @SpringBootTest、MockMvc、Mockito | 单元测试代码、测试报告、覆盖率报告 |
| B7 | 实现 RESTful 接口并生成在线文档 | @RestController、@RequestMapping、Knife4j | 完整接口 + 可在线访问的接口文档 |
| B8 | 使用 AOP 与拦截器实现日志与权限 | @Aspect、HandlerInterceptor | AOP 切面代码 + 拦截器 + 日志数据 |

> 每项任务的详细任务书见 `04_课堂及课后作业_任务书合集.md`，每项任务的详细评分细则见 `05_课堂及课后作业_评分细则.md`。

## 五、评价方式

1. **智慧教学平台自动评价**：通过 CI 脚本自动运行单元测试、接口测试、构建命令，按通过率给出基础得分。
2. **教师评审**：针对代码规范、文档质量、答疑情况给出附加分或扣分。
3. **小组互评**：每次作业结束后 3 天内，同学可在平台对其他小组作业进行互评（仅用于参考，不纳入总分）。

## 六、重做与补交

- 首次提交不合格（<60）允许重做 1 次，重做最高分 75 分。
- 缺交作业按 0 分计，但需补交以作为学习记录。

## 七、记录保留

所有作业、测试报告、评分记录在智慧教学平台与教研室共同保留至少 3 年。
