# 课堂及课后作业实施细则

B3~B8 合计 30%，依托"竞赛登记管理系统"真实项目，覆盖 T3~T8。

一、考核项概览

| 考核项 | 课程目标 | 考核内容 | 权重 |
| --- | --- | --- | --- |
| B3 | T3 | 创建项目并成功启动服务 | 3% |
| B4 | T4 | 整合 MyBatis-Plus 实现增删改查 | 7% |
| B5 | T5 | 实现自定义 Starter 自动装配 | 5% |
| B6 | T6 | 编写 Service 单元测试与接口测试 | 5% |
| B7 | T7 | 实现 RESTful 接口并生成文档 | 4% |
| B8 | T8 | 使用 AOP 实现日志记录切面 | 6% |

二、依托项目与技术栈

项目名称：竞赛登记管理系统。核心模块：用户管理、竞赛管理、报名管理、成绩管理、系统日志、权限与接口文档。技术栈：后端 Spring Boot 2.7.x/3.x + MyBatis-Plus + MySQL 5.7 + Redis；前端 Vue 2 + ElementUI + axios；文档 Knife4j/Swagger；测试 JUnit 5 + MockMvc。

三、作业通用要求

提交物：源码仓库链接、README、任务报告、运行/测试截图；提交方式：智慧教学平台作业系统；时间节点：对应教学单元结束后 1 周内；平台自动评价（构建、测试、覆盖率）+ 教师复核；不合格可重做 1 次，最高 75 分；缺交按 0 分但需补交。

四、任务简表

| 编号 | 任务名称 | 交付物 |
| --- | --- | --- |
| B3 | 搭建工程骨架 | 可启动的 Spring Boot 工程 |
| B4 | CRUD 与事务 | Service/Mapper/Controller + 单测 |
| B5 | 自定义操作日志 Starter | 独立 Starter 模块 + 原理报告 |
| B6 | 单元与接口测试 | 测试代码、JaCoCo 报告 |
| B7 | RESTful 接口与文档 | 接口 + 在线文档 + Postman 集合 |
| B8 | AOP 与拦截器 | 切面 + 拦截器 + 日志数据 |

各任务完整任务书见《课堂及课后作业_任务书合集》；评分 Rubric 见《课堂及课后作业_评分细则》。

五、记录保留

作业、测试报告、评分记录在智慧教学平台与教研室共同保留至少 3 年。
